How to Use PCR

Every scoring round, the Quotient Scoring Engine logs into your services (such as SSH, Active Directory/LDAP, SQL, SMB, or Web/Mail) like a real user to award points.

When you change an account's password on your machine to lock out Red Team, the Scoring Engine will fail to log in unless you also submit a Password Change Request (PCR) here with the new password.

  1. First, change the password on the actual machine (e.g., passwd, Active Directory Users & Computers, SQL).
  2. Check which Credential List matches that service using the selector at the top of this page (a competition often has multiple separate lists for Windows Domain, Linux SSH, Databases, etc.).
  3. Click any username badge (or click Pre-fill all usernames), enter the new password in username,password format, and click Submit Changes.

Enter one credential per line in this format:

username,password

Examples:

administrator,MyNewP@ss123
john.doe,SecurePassword!
"quoted_user","quoted,password"

Tip: Enable "Strip surrounding quotes" in Advanced Options to automatically remove outer quotes. Passwords may contain commas.

The Reset List to Defaults button restores all credentials in the selected credential list to their original competition default values.

Warning: This action overwrites all custom passwords in the selected list and cannot be undone.
